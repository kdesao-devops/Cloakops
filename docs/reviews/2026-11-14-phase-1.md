| # | Finding | Triage | Fix | Regression test |

| 1 | IPv4 followed by `/<digit>` that is not a valid prefix (URL path `/1/status`, `/33`) detected by no rule | Real leak (verified) | Address rule defers to the CIDR rule only when a valid prefix follows | `test_ipv4_followed_by_a_slash_that_is_not_a_prefix` |
| 2 | CLI flag value starting with `-` (`--password=-x...`) skipped | Real leak (verified) | After `=`, a leading dash is part of the value; after a space it is the next flag | `test_cli_value_starting_with_a_dash_after_equals` |
| 3 | Short pseudonyms could be common words; re-injection would rewrite them everywhere | Real (local answer corruption) | Pseudonyms in `STOP_WORDS` are rejected; ADR 0011 | `test_pseudonym_is_never_a_common_word` |
| 4 | `unmask` on an expired session printed pseudonyms with exit 0 | Real | Error, exit 2; ADR 0016 | `test_unmask_of_an_expired_session_is_an_error` |
| 5 | Concurrent `mask` on one session: last writer drops mappings | Real | `flock` around load -> mask -> save; also fixed a `mkdir` race the new test exposed | `test_concurrent_masks_on_one_session_keep_every_mapping` |
| 6 | Stale `.tmp` file with loose permissions reused for the session write | Real | `mkstemp` (fresh 0600 file) + atomic rename, also for the seed file | `test_stale_temporary_file_cannot_make_a_session_readable` |
| 7 | Seed terms copied into every session file | Real (erasure did not work) | Seed-only terms are never exported | `test_seed_terms_are_not_exported_to_the_session` |
| 8 | `config.internal_suffixes or DEFAULT` (CLAUDE.md rule) ignored an explicit `[]` | Real | `is not None` | `test_explicitly_empty_internal_suffixes_are_respected` |
| 9 | `--paranoid` re-scan was O(characters x replacements) | Real (performance) | Replaced-position mask built once | covered by existing re-scan tests |
| 10 | A refused document still taught terms and created mappings | Real (library/proxy use) | `mask` is all-or-nothing: session rollback + propagator snapshot | `test_failed_mask_leaves_no_trace_in_the_session` |

Also corrected while checking specs against code: ADR 0003 claimed pseudonymized secrets are
"guaranteed invalid"; they are invalid by construction only for checksummed formats, otherwise
random 100+ bit values.
